# Rectangular FrozenLake staircase stages

Three fixed geometric examples with one, two and three connected stages.
The original FrozenLake domain and unit-cost movement rules are unchanged.
Reference costs are independently computed, including the possible contribution
of proper cyclic policies. See the [campaign guide](../../../campaigns/journal_frozenlake_stages/README.md).

This exploratory collection is separate from ICAPS inputs, earlier recovery
maps and the non-geometric serial-composition diagnostics. It is not a final
paper benchmark selection.
